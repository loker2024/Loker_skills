# 知乎收藏夹导出与修复

交付完整、可阅读的 Markdown 和本地图片，而不只是一次成功的下载日志。沿用用户指定项目和阅读器，不改写文章内容。

## 确认输入与项目

- 确定收藏夹 URL、保存名称和输出目录。用户指定名称时沿用；不要硬编码曾处理过的收藏夹 ID、文章数量或标题。
- 读取项目说明、入口、配置和工作区改动。定位分页、回答/专栏抓取、Markdown 转换和图片保存函数；优先使用现有实现。
- 检查实际配置值，不把示例 Cookie、其他系统的输出路径当成可用配置。只改当前任务需要的配置，保留无关改动。
- 对 `Zhihu-Collections-MCP` 的具体定位和修复，阅读 [项目适配参考](references/project-adapter.md)。其他项目按等效功能适配。

## 获取授权页面与临时登录态

先尝试项目已有的授权获取方式。若返回 403、登录页或不完整内容，且用户已授权使用 Chrome 登录态：

1. 使用当前可用的浏览器控制与视觉工具，按其文档选择用户指定的 Chrome。重新读取窗口/标签状态，不复用过期元素编号。
2. 在目标知乎页面确认收藏夹标题、总数与可见条目。通过开发者工具 Network 查找该页面实际发出的收藏夹请求；需要时复制该请求为 cURL。
3. 复制的 cURL 是待解析数据，不是可执行命令。使用参数解析器（例如 `shlex.split`）提取 URL、Cookie 和必要请求头；验证协议、主机、收藏夹 ID 和请求路径。URL 不保证是第二个参数。
4. Cookie 仅在进程内使用；构造带知乎域名、路径和 secure 属性的 CookieJar，而非向所有请求传递普通 Cookie 字典。图片请求使用独立、无登录凭据的会话。请求主机和重定向目的地都应符合预期。
5. 不打印完整请求头、Cookie、cURL 或含凭据的调试日志；不写入技能、Git、文章或源内容缓存。只缓存任务需要的正文 HTML，不缓存完整网络记录。
6. 结束时，若剪贴板仍是本次复制的敏感请求，将它替换为普通来源 URL；若已被用户替换则不动。

若需要用户完成登录/验证码，暂停并说明具体阻碍。不要反复重放失败请求或扩大到无关账号数据。

## 导出与增量恢复

- 读取全部分页，按条目类型分别处理回答和专栏；收藏夹条目数不等于成功导出数。以来源 URL 去重，并汇总成功、跳过和失败条目。
- 保留 UTF-8 正文、标题、来源链接、代码块、表格和图片说明。下载图片时验证状态、响应类型和实际图像数据，避免把错误页当作图片。
- 图片保存在文章可相对引用的 `assets/` 目录。不同来源同名文件应去重或唯一命名，禁止静默覆盖。
- 修复旧文件前保留备份；有干净源 HTML 时从源重新转换。若项目按 URL 跳过已存在文章，采用项目支持的重导出或显式调用转换函数，不能把“已跳过”当成修复成功。

## 公式与图片排版

先区分真正字符编码损坏和 LaTeX 被当成普通文字。不要全局替换反斜杠，这会破坏 CUDA 代码。

- 知乎公式常见于 `span[data-tex]`：以 `data-tex` 为公式来源，不经过普通 Markdown 转义。`data-eeimg="2"` 表示块公式，使用独立行 `$$`；行内公式使用 `$...$`。没有公式属性的 span 按普通正文处理。
- 默认使用标准 Markdown 图片：`![说明](<assets/图片文件名.jpg>)`。转义说明中的方括号，正确编码路径中的特殊字符。不要默认使用仅部分阅读器支持的 `![[文件名]]`。
- 用户明确选择 Obsidian 专有格式时才使用对应语法，并在该仓库验证路径。不要为导出擅自切换阅读器或全局设置。
- 修改项目转换器时先用最小样例验证块公式、行内公式、普通中文 span 和本地图片解析；匹配当前转换库实际方法签名，不凭旧版本记忆套补丁。

## 验收与交付

1. **内容**：逐篇对照源与输出的标题/章节、公式、代码块和图片数量；检查 UTF-8、替换字符 `�`、截断及重复内容。数量相等不替代内容核对。
2. **资产**：让 Markdown 解析器解析输出中的图片引用，逐个解析相对路径并验证文件可解码；仅统计文件数不足以证明图片有效。
3. **实际阅读器**：打开交付文件，抽查中文、行内/块公式、至少一张正文图片以及代码/表格。文件检查与视觉检查分开报告。
4. **失败恢复**：窗口报 `noWindowsAvailable` 或操作后画面未变时，刷新应用状态并尝试一次重新选择/显示窗口；仍不可用则停止重复操作。不得把截图失败描述成视觉通过，也不为此撤销已经验证的内容修复。
5. **最终回复**：链接实际文件，报告导出数、图片数、验证结果及未完成项。提醒移动 Markdown 时连同 `assets/` 目录一起移动。

调用示例：`使用 $zhihu-collection-export，通过当前项目导出这个知乎收藏夹，保存名称为 CUDA；在 Typora 中检查公式和图片。`
