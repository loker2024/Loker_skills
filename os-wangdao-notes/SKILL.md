## 1. 解析用户指令

「整理 os 2.3.2」= 整理操作系统第 2.3.2 节。先 `ls 王道课件/第X章 …/`，用 `2.3.2` 前缀匹配 PDF。**一个节号可能对应多个 PDF**（如 `2.3.2_1 进程互斥的软件实现方法.pdf`、`2.3.2_2 进程互斥的硬件实现方法.pdf`）。

**合并还是拆分？** 看已有先例：

| 情况 | 做法 | 先例 |
| --- | --- | --- |
| 多个 PDF 属于同一主题的不同侧面 | 合成 1 个笔记文件，文件名用复习指导的节标题 | `2.1.6 线程.md`（3 个PDF）、`2.2.5 调度算法.md`（3 个PDF）|
| 多个 PDF 主题不同 | 拆成 `X.Y.Z_1 xxx.md` / `X.Y.Z_2 xxx.md` | `2.1.5_1 进程通信.md`、`2.1.5_2 信号.md` |

不确定时查教材目录：`操作系统/教材/2027王道*.pdf` 的目录页（PDF 第 8 页）能给出该节的标准标题，用它当文件名。

**第 1 步：逐页文字**
```python
import pymupdf, os
doc = pymupdf.open(pdf_path)
for i, page in enumerate(doc):
    print(f"----- PAGE {i+1} -----"); print(page.get_text())
```
注意：王道课件的**代码块是图片**，`get_text()` 拿不到。必须靠第 2 步看图补齐；也可用 `page.get_images(full=True)` + `doc.extract_image(xref)` 拿到原始代码图。

**第 2 步：渲染整页 PNG 来看图**（判断哪页有关键图）
```python
m = pymupdf.Matrix(144/72, 144/72)   # → 1920x1080，与已有 assets 尺寸一致
page.get_pixmap(matrix=m).save(out_png)
```
用 Read 工具直接看渲染出来的 PNG 判断图的内容。

**第 3 步：只导出「关键图」页**，同样 144 DPI。已有 assets 全是**整页导出、不裁剪**（1920x1080 / 1600x900 / 1734x975）。
